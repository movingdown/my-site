만든 것들

직접 만들어본 프로젝트. 소스 코드는 GitHub에서 확인할 수 있어요.

  • StudyPlanner

    Java Swing으로 만든 학습 일정 관리 데스크톱 앱. MVC 패턴으로 구조를 나누고, 일정을 텍스트 파일에 저장·불러옵니다.

    #Java #Swing #MVC

  • SmartFileOrganizer

    뒤섞인 폴더의 파일을 확장자 기준으로 이미지·문서·동영상 등 카테고리별로 자동 분류해 주는 Python 데스크톱 도구. Tkinter만 사용해 외부 의존성 없이 동작합니다.

    #Python #Tkinter #Automation

  • TrendAnalyzer

    관심 키워드의 트렌드 데이터를 수집·분석해 시간 흐름에 따른 변화를 한눈에 보여주는 도구. 데이터 시각화로 인사이트를 빠르게 확인할 수 있습니다.

    #Python #DataAnalysis #Visualization

  • ExamSurvival

    시험 기간의 캠퍼스를 무대로 한 탑다운 픽셀 로그라이크 게임. 외부 라이브러리·이미지·사운드 파일 없이 바닐라 JS와 Canvas, Web Audio API만으로 구현했습니다.

    #JavaScript #Canvas #Game

  • AlgoVisualizer

    Python과 Tkinter로 만든 정렬 알고리즘 시각화 도구. 버블·선택·퀵 정렬의 진행 과정을 막대 그래프 애니메이션으로 보여주고, 속도와 배열 크기를 실시간으로 조절할 수 있습니다.

    #Python #Tkinter #Algorithm
